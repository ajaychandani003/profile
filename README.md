- **Targeting Reticle Cursor**: Lerp-smoothed cursor with 4-corner snap brackets that lock onto interactive targets.
- **Porthole Radar**: Profile porthole with a continuous 360° radar sweep and telemetry matrix.
- **Planetary Project Showcase**: Orbital project cards highlighting real enterprise client deliveries with category filtering and interactive case study modals.
- **Deep Space Network (DSN) Downlinks**: Direct transmission channels for downloading official resume PDFs and technical assets.
- **Constellation Experience Timeline**: Comprehensive career history documenting 13+ years of client leadership and academic credentials (MCA, BCA).
- **Orbital Skills Cloud**: Filterable technical skills matrix covering eCommerce, Backend/Cloud, AI, and DevOps.
- **Mission Control Transmission Terminal**: 1-click clipboard copy for email & phone, instant WhatsApp recruiter chat, and contact dispatch.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/ajaychandani003/profile.git

# Navigate to the project directory
cd profile

# Install dependencies
npm install
```

### Development Server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### Production Build
```bash
npm run build
```
The optimized production bundle will be generated in the `dist/` directory.
